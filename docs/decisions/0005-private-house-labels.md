# 0005: name local houses by street and number

Sri asked for his houses to use their street and number. Building now derives a stable house key from the delivery address and keeps display names in an ignored private sidecar. Distinct addresses within a postcode area stay separate.

The local app loads names only when the sidecar matches the order file's source and generation time. Manual names take precedence. The normalised order export continues to contain coarse areas and opaque keys. Public demo names are fictional, and screenshots continue to use the demo only.

An absent next-page link is the end of the returned listing, not proof that the account has no older orders. The interface and fetcher should describe imported coverage without claiming that older history is unavailable.
